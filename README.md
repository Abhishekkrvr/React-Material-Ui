# Full Material-UI Course 🎨

This repository contains all the code and examples from my **complete Material-UI (MUI) course**.  
It’s designed to help learners build beautiful, responsive, and accessible React applications using Material-UI components.

---

## 📚 Topics Covered
- Material-UI setup and theming  
- Typography, colors, and responsive design  
- Layout components: Grid, Box, Container  
- Navigation: AppBar, Drawer, Tabs  
- Forms: TextField, Select, Checkbox, Radio, validation  
- Feedback components: Snackbar, Dialog, Progress  
- Icons and customization  
- Building real-world UI projects with MUI
